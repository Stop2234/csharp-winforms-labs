# Лаборатории по Windows Forms

Лабораторные работы по программированию на C# с интерфейсом **Windows Forms**:
от базовых элементов управления до графики GDI+, анимации на таймере и
рисования в фоновых потоках.

Все приложения нацелены на **.NET 7 (Windows)** и используют `System.Windows.Forms`
и `System.Drawing` (GDI+). Код оставлен таким, каким был сдан.

## Технологии

- **C#**, **.NET 7** (`net7.0-windows`), `OutputType=WinExe`;
- **Windows Forms** (`System.Windows.Forms`) — `Form`, `Button`, `Label`,
  `TextBox`, `ListBox`, `RadioButton`, `Timer`;
- **GDI+** (`System.Drawing`) — `Graphics`, `Pen`, `SolidBrush`, методы
  `DrawEllipse`, `DrawArc`, `FillPie`, `FillRectangle`, `DrawLine`;
- обработчики событий (`Click`, `Load`, `Paint`, `Tick`);
- **потоки** (`System.Threading.Thread`) в `lab15` и `lab17`;
- **LINQ** в `lab06`.

## Сборка и запуск

**Windows Forms — технология только для Windows.** Собрать и запустить эти
проекты можно на Windows с установленным **.NET SDK 7.0** (или более новым,
умеющим собирать `net7.0-windows`). На Linux/macOS WinForms не поддерживается.

```bash
# из папки работы (например, lab08)
cd lab08
dotnet build          # сборка
dotnet run            # запуск приложения
```

Альтернатива — открыть `.sln` в Visual Studio (2022+) и запустить проект
`WinExe`.

## Известные ограничения

1. **Только Windows.** Windows Forms не кроссплатформенна: проекты не соберутся
   и не запустятся на Linux/macOS. Нужен Windows.

2. **Сборка не проверялась: в окружении, где готовился репозиторий, нет
   .NET SDK** (установлены только рантаймы). Все проекты нацелены на
   `net7.0-windows`; для сборки нужен .NET SDK 7.0+ на Windows либо
   Visual Studio. Это ограничение окружения, а не ошибка исходников.

3. **Нумерация приведена к последовательной.** Исходные папки были названы
   непоследовательно («WinFormsApp1 лаб N» и «лаба N»), поэтому работы
   пронумерованы по порядку выполнения, а исходные имена сохранены в таблице.

4. **Не включены:** ранние тривиальные заготовки `App` и `App1` (пустые
   обработчики), `лаб 6` (побайтовая копия работы `лаба4`), `лаб 12` и
   `13 лаб` (пустые, без кода), `ConsoleApp1` (консольная программа, не
   WinForms), а также архивы `*.zip`, каталоги `bin`, `obj`, `.vs` и
   служебные файлы Visual Studio.
